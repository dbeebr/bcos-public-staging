# Project-Level Instructions — __CELL_NAME__

This is the one agent-agnostic project-instruction body for __REPOSITORY__.
Paste the block below into whichever "project" concept your app surface
exposes (a ChatGPT Project, a Claude Project, a workspace instruction file,
a local host's system prompt). App-specific activation notes
(`instructions/APP-INSTRUCTIONS-*.md`) only say where to paste it.

This file is generated by `scripts/render-instructions.py` from the shared
core (`templates/PROJECT-INSTRUCTIONS.template.md`), the Cell profile
(`.bcos/CELL-PROFILE.yaml`) and the generated Procedure Index in
`CONTEXT_INDEX.md`. Do not edit it by hand: `./scripts/validate-cell.sh`
fails on a hand-edited block and warns when it is stale. Re-render with
`python3 scripts/render-instructions.py refresh`, then re-paste.
